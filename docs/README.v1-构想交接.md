## 一、这是什么（一句话）

把 408 的知识**按考试的理解方式重排**成一张图，而不是把教材目录平铺一遍。

核心区别：

- 教材 / 教辅是「**按章节线性讲**」
- 这张图要能回答：**为什么会出现这个技术？它解决了什么问题？又引入了什么新问题？**

一句话定位：**考试特化的「理解化用」，不是参考资料的目录拷贝。**

## 五、四科的主线（草案 · 可推翻）

- **操作系统**
  资源管理 —— 处理机 / 内存 / 文件 / 设备四大资源，
  各自「管什么 → 怎么管 → 引出什么新问题」；外加并发与同步。
- **数据结构**
  逻辑结构 → 存储结构 → 操作实现 → 复杂度权衡；
  按「**为什么需要这种结构**」把线性表 / 树 / 图 / 查找 / 排序串起来。
- **计组**
  冯·诺依曼「存储程序」→ CPU 如何取指执行 → 存储层次（Cache / 主存 / 虚存）
  为何层层引入 → IO 与总线。
- **计网**
  分层到底解决了什么问题 → 每层协议是上一层的「方案」又带来哪些「新问题」
  → 用端到端视角把各层串起来。

## 六、现成能借的东西（不用从零写）

### 渲染层参考

| 位置 | 内容 |
|---|---|
| 桌面 `knowledge-graph-3d/` | 3D 图谱渲染层 + 内容页模板（Three.js + d3-force-3d + Vite） |
| GitHub `klzw12/knowledge-graph-408` | 考研三域骨架（408 四科空壳 + 同一套渲染层） |

**预览方式**（Vite）：

```bash
npm install
npm run dev        # 浏览器打开 http://localhost:5173
```

**数据结构**（`src/domains/<域>.js`，导出 `{ root, relations }`）：

```
id           唯一标识（跨科连线靠它）
label        图上显示的名字（可带 emoji）
color        节点颜色（域内逐层加深）
description  点击时信息面板显示
content.summary   需要时附英文术语 / 一句话定位
src          内容页路径（public/pages/<层级>/<id>.html）
```

**交互**：拖拽旋转 / 滚轮缩放 / 点击 flyTo / 双击开内容页 / 右键复位。

> 也可以完全另起一套，**不锁死**。
> 但建议先复用：能最快看到样子，省掉 80% 的脚手架工作。
